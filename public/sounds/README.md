# Optional real sound recordings

The game synthesises all of its sounds, so this folder can stay empty.
To use real recordings, drop files here with **exactly these names** (`.mp3`, `.ogg` or `.wav`):

| File | When it plays | Tip |
| --- | --- | --- |
| `chip` | placing a chip | very short (< 0.3 s) |
| `dice` | the throw | about 1.5–2.5 s of dice rattling and settling. When this file exists it replaces the synthesised bounces |
| `win` | you won the round | 1–2 s |
| `lose` | you lost the round | 1–2 s |

Any file you leave out keeps its synthesised sound. Only use recordings you made yourself
or that are licensed for this use (for example CC0 sound packs). No restart is needed, just reload the page.
